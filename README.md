# Don't Eat Me!

2-player 3D co-op food brawler with accounts and a saved economy.

- Play: https://dont-eat-me.onrender.com (server version) or https://ibrahimbugha.github.io/eat-me/
- `server.js`: Node + Postgres API (accounts, bank, unlocks, upgrades, daily reward, leaderboard)
- `public/index.html`: the game. `index.html` in the root is a copy for GitHub Pages: after editing the game, run `cp public/index.html index.html`.
